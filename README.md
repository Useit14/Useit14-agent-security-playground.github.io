# Agent Security Playground

Демо **непрямой инъекции промпта** для доклада.

Агент получает «сделай summary этой страницы», читает **сырой HTML**, видит скрытую инструкцию и шлёт POST на callback.

Инъекция лежит в HTML статикой (почти невидимый текст).

---

## Быстрый старт

1. Cкопируйте уникальный Webhook URL.
2. В `index.html` на свой URL.
3. Отдайте агенту `index.html` (URL или файл).
4. Промпт: _«Сделай summary этой страницы»_.
5. Смотрите webhook — туда прилетят данные.

Callback: webhook.site, n8n, Make, Telegram-бот — любой endpoint с логом body.

---

## Структура

```
index.html          # статья + статическая инъекция
src/css/style.css   # стили статьи
README.md
```

---

## Инъекция

- **Сокрытие:** почти невидимый текст (`color: #fff`, `font-size: 1px`, `opacity: 0.01`) — человек не замечает, в сыром HTML есть.
- **Формулировка:** integrity — «проверка целостности источника» + обязательный POST.

Текст — блок в конце `index.html` (перед `</body>`). Меняйте только URL callback.

---

## Что показывает демо

1. LLM не отличает инструкцию от данных.
2. Агент действует с правами workflow (confused deputy).
3. «Красная кнопка» не отменяет уже ушедшие данные.
